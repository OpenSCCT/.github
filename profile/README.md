# OpenSCCT

Community projects for **Tom Clancy’s Splinter Cell Chaos Theory**. Start with the
[project hub](https://master.lumbridge.co.uk/) or [download the launcher](https://github.com/OpenSCCT/OpenSCCT/releases/latest).

| Choose an edition | Play | Development |
|---|---|---|
| **PlayStation 2** | Load your own Chaos Theory ISO with PCSX2. Keep original and patched disc images side by side. | [PS2 executable research](https://github.com/OpenSCCT/OpenSCCT/tree/main/decomp/ps2) |
| **Original PC / Steam** | Start the campaign, co-op or Versus from your installation. Enhanced and Reloaded are optional Versus profiles. | [PC executable research](https://github.com/OpenSCCT/OpenSCCT/tree/main/decomp/pc) |
| **OpenSCCT Unreal** | Play the modern Windows edition of Spies vs. Mercenaries with community maps. | [Unreal client and bridge](https://github.com/OpenSCCT/OpenSCCT-Unreal) |

## Follow development

[Per-executable progress](https://master.lumbridge.co.uk/progress) tracks original
builds and verified matching code. [Release notes](https://master.lumbridge.co.uk/changelog)
cover playable builds. The [core repository](https://github.com/OpenSCCT/OpenSCCT)
contains the launchers, website, shared simulation, Godot client and research tools.

## Create and play maps

- Build maps with [OpenSCCT Editor](https://github.com/OpenSCCT/OpenSCCT-Editor). The [shared content](https://github.com/OpenSCCT/OpenSCCT-Content) and [cooked Unreal maps](https://github.com/OpenSCCT/OpenSCCT-Unreal-Content) have their own release channels.
- For original PC Versus, use the [Reloaded Editor fork](https://github.com/OpenSCCT/SCCT_Versus_Reloaded_Editor), [Map Manager](https://github.com/OpenSCCT/SCCT-Map-Manager) and [community map collection](https://github.com/OpenSCCT/SCCT-Maps).
- See the upstream [Enhanced SCCT Versus releases](https://github.com/Joshhhuaaa/EnhancedSCCTVersus/releases) and [Versus Reloaded features](https://allypal.github.io/SCCT_Versus_Reloaded/features/) for changes to the original multiplayer game.
